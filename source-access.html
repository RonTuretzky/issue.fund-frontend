The core repository requires access

Issue.fund’s public website and user guides are maintained separately from its private core repository. Historical links to contract source, deployment records, internal testing and operations guides, and the archived implementation require authorization from the repository owner.

The public frontend repository contains the static website, public deployment configuration, and font licenses. It does not contain backend or contract source. The developer setup commands in the public guides require access to the core repository.

The live contract addresses and public chain-explorer links remain available in Contracts and supported limits. To report a website issue, use the public frontend issue tracker. Please do not post credentials or personal email receipts.
